# VideoCompass AI 2.1 — занятие №4

Отдельная версия учебного сервиса анализа публичных YouTube-видео. Проект занятия №3 не изменяется и продолжает работать независимо.

- Основной сайт: https://videocompass.vercel.app
- Резервный адрес: https://video-compass-ai-4216-lesson4.vercel.app
- GitHub: https://github.com/Konstantin1043/video-compass-ai-4216-lesson4

Пользователь получает доступный транскрипт ролика через Apify и структурированный разбор на русском, английском или латышском языке через Gemini. Для нового внешнего анализа нужен один внутренний кредит; сохранённая история и свежий общий кэш открываются бесплатно.

## Возможности версии 2.1

- регистрация и вход через Supabase Auth, сессия в `HttpOnly` cookie;
- 10 бесплатных кредитов в день по часовому поясу `Europe/Riga`;
- устойчивые этапы «транскрипт → Gemini → сохранение» и продолжение после перезагрузки;
- идемпотентные задания, блокировка параллельной обработки и автоматический возврат кредита при ошибке или зависании;
- общий кэш публичных роликов на 24 часа без повторного списания;
- до 30 обычных анализов на 30 дней и избранные до ручного удаления;
- история, поиск, фильтр языка, избранное, удаление и возобновление;
- проверяемый JSON-результат: 8 разделов, оценка, 5–7 пунктов резюме, 5–12 глав и 3 вопроса;
- вкладки «Анализ», «Транскрипт», «Главы», поиск по транскрипту и безопасные тайм-коды;
- демонстрационный результат без регистрации;
- экспорт в TXT, Markdown и PDF с поддержкой RU/EN/LV;
- отзываемая публичная ссылка на 30 дней без email, баланса, истории и транскрипта;
- Cloudflare Turnstile, проверка Origin, ограничения запросов в Supabase и безопасные журналы;
- показ пароля, удаление аккаунта после повторной проверки пароля;
- политика конфиденциальности на трёх языках.

## Архитектура

```text
index.html, styles.css, app-v21.js        интерфейс 2.1
api/analysis/start.js                     запуск, кэш и резервирование кредита
api/analysis/step.js                      следующий устойчивый этап
api/analysis/status.js                    состояние и продолжение задания
api/analysis/history.js                   история и избранное
api/share.js                              публичные ссылки
api/export/pdf.js                         PDF-экспорт
api/auth/, api/account/                   аккаунт и сессия
api/cron/cleanup.js                       ежедневная очистка
lib/                                      Apify, Gemini, Supabase и безопасность
supabase/migrations/                      SQL-схема и RLS
test/                                     автоматические тесты
```

Основная модель — `gemini-3.5-flash-lite`, резервная — `gemini-3.1-flash-lite`. Модель `gemini-3.7-flash` не используется.

## Настройка Supabase

1. Выполнить существующую миграцию `supabase/migrations/202608270001_auth_and_daily_credits.sql`.
2. Выполнить новую миграцию `supabase/migrations/202608280001_video_compass_21.sql`.
3. Оставить включённым RLS. Браузеру не выдаётся прямой доступ к заданиям, общим результатам, ссылкам и событиям ограничений.
4. Взять в **Project Settings → API** значения Project URL, Publishable key и отдельный серверный Secret key.
5. После создания Turnstile включить CAPTCHA в **Authentication → Bot and Abuse Protection** и указать секрет Cloudflare.

Secret key обладает повышенными правами: его нельзя помещать в браузерный JavaScript, GitHub, логи или архив.

Обязательные для полного режима:

```text
APIFY_API_TOKEN
GEMINI_API_KEY
SUPABASE_URL
SUPABASE_PUBLISHABLE_KEY
SUPABASE_SECRET_KEY
RATE_LIMIT_SECRET
CRON_SECRET
PUBLIC_SITE_URL=https://videocompass.vercel.app
MAX_EXTERNAL_ANALYSES_PER_DAY=100
MAX_EXTERNAL_ANALYSES_PER_MONTH=1000
```

После настройки Cloudflare:

```text
TURNSTILE_SITE_KEY
TURNSTILE_REQUIRED=true
```

Дополнительно для страницы конфиденциальности:

```text
PUBLIC_CONTROLLER_NAME
PUBLIC_CONTACT_EMAIL
```

Настоящие значения вводятся только в панелях сервисов для Production и Preview. `.env.example` содержит только пустые примеры.

## Контроль расходов

Проект рассчитан на Vercel Hobby, Supabase Free, Gemini Free Tier, Apify Free и Cloudflare Turnstile Free. Банковская карта и автоматическая оплата не подключаются. Дневной и месячный защитные лимиты останавливают создание новых внешних заданий до вызова Apify и Gemini; кэш, история, избранное и публичные ссылки продолжают работать.

## Локальная проверка

Требуется Node.js 22 или новее.

```powershell
npm install
npm test
npm run dev
```

Локальная страница: `http://127.0.0.1:3000`. Полный облачный сценарий требует переменных окружения и применённых миграций Supabase.

## Безопасность

- серверные ключи не возвращаются клиенту;
- пароль не сохраняется приложением и обрабатывается Supabase;
- изменение кредита выполняется атомарными SQL-функциями;
- prompt injection внутри транскрипта явно игнорируется;
- JSON Gemini нормализуется, а тайм-коды сверяются с сегментами Apify;
- AI-текст создаётся безопасными DOM-узлами и не исполняется как HTML;
- публичная ссылка содержит случайный токен, в базе хранится только его SHA-256;
- IP используется только как HMAC-отпечаток для ограничения запросов;
- ежедневная очистка удаляет просроченные ссылки, ограничения, обычную историю и незавершённые задания.

Автоматический набор проверяет старый совместимый API и функции 2.1: языки, модель и fallback, кэш, лимиты, RLS, возврат кредита, структуру Gemini, тайм-коды, историю, безопасность, PDF и мобильный интерфейс.

```powershell

```
