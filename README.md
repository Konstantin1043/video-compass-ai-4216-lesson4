# VideoCompass AI — версия к занятию №4

Отдельная версия учебного сервиса анализа YouTube-видео. Предыдущий проект занятия №3 остаётся самостоятельным и продолжает работать по прежней ссылке.

Сайт: https://video-compass-ai-4216-lesson4.vercel.app

GitHub: https://github.com/Konstantin1043/video-compass-ai-4216-lesson4

Пользователь регистрируется, получает 10 бесплатных анализов в день, вставляет ссылку на публичное YouTube-видео и получает структурированный разбор на русском, английском или латышском языке.

## Возможности

- регистрация и вход по электронной почте и паролю через Supabase Auth;
- защищённая сессия в `HttpOnly` cookie — токены не доступны клиентскому JavaScript;
- баланс восстанавливается **до 10 кредитов** каждый день в 00:00 по часовому поясу `Europe/Riga`;
- один кредит списывается только после успешного нового анализа;
- при ошибке Apify, Gemini или базы зарезервированный кредит автоматически возвращается;
- сохранённый в памяти страницы результат открывается повторно бесплатно;
- обычные ссылки YouTube, `youtu.be`, Shorts, Live и Embed;
- интерфейс и AI-ответ на RU, EN и LV;
- восемь интерактивных разделов результата;
- 5–7 проверенных кликабельных тайм-кодов в разделе «Краткое резюме», если Apify вернул временные сегменты;
- безопасное хранение всех ключей только на сервере Vercel.

## Архитектура

```text
index.html, styles.css, script.js       интерфейс
api/auth/                               регистрация, вход, сессия и выход
api/analyze.js                          получение транскрипта и AI-анализ
lib/supabase.js                         Auth и атомарные операции с кредитами
supabase/migrations/                    SQL-схема базы данных
test/                                   автоматические тесты
scripts/dev-server.js                   локальный сервер
```

Внешние сервисы:

1. Supabase хранит пользователей, профили, баланс и журнал операций.
2. Apify Actor `scrape-creators/best-youtube-transcripts-scraper` получает субтитры.
3. Gemini `gemini-3.5-flash-lite` анализирует транскрипт.
4. Vercel публикует страницу и запускает серверные функции.

## Настройка Supabase

1. Создайте отдельный проект Supabase.
2. Откройте **SQL Editor**, вставьте содержимое файла `supabase/migrations/202608270001_auth_and_daily_credits.sql` и выполните запрос один раз.
3. В **Authentication → Sign In / Providers → Email** отключите подтверждение электронной почты. Для этого учебного проекта пользователь должен получать сессию сразу после регистрации.
4. В **Project Settings → API** скопируйте:
   - Project URL → `SUPABASE_URL`;
   - Publishable key → `SUPABASE_PUBLISHABLE_KEY`.
5. Не используйте и не публикуйте `service_role` или Secret key — проекту они не нужны.

Ежедневное восстановление выполняется лениво и атомарно при следующем обращении пользователя. Планировщик не требуется: если в Риге наступил новый календарный день, база сначала устанавливает баланс в 10, а затем выполняет операцию.

## Переменные Vercel

```text
APIFY_API_TOKEN
GEMINI_API_KEY
SUPABASE_URL
SUPABASE_PUBLISHABLE_KEY
```

Все четыре переменные добавляются для Production и Preview. Настоящие значения нельзя отправлять в чат, записывать в GitHub или помещать в ZIP-архив. `.env.example` содержит только пустые названия.

## Локальная проверка

Требуется Node.js 22 или новее.

```powershell
npm test
npm run dev
```

Страница откроется по адресу `http://127.0.0.1:3000`. Полный вход и анализ требуют локальных переменных окружения либо опубликованного проекта Vercel.

## API анализа

Авторизованный клиент отправляет:

```json
{
  "youtubeUrl": "https://youtu.be/VIDEO_ID",
  "language": "ru",
  "requestId": "случайный UUID"
}
```

`requestId` не позволяет повторно списать кредит за тот же запрос. Неизвестный язык отклоняется до вызова внешних сервисов. Токены Supabase, Apify и Gemini никогда не возвращаются в JSON.

## Безопасность и ограничения

- Row Level Security включён для профилей и журнала кредитов.
- Изменение баланса доступно только через серверные SQL-функции от имени вошедшего пользователя.
- Списание использует резервирование → подтверждение или возврат и устойчиво к параллельным запросам.
- Размер тела запроса, частота запросов и время ожидания внешних API ограничены.
- В HTML AI-ответ не исполняется: весь текст создаётся через безопасные DOM-узлы.
- Поддерживается один публичный ролик за запрос; закрытые видео и ролики без субтитров не анализируются.
- Длинный транскрипт сокращается до 60 000 символов целыми сегментами с сохранением начала, середины, конца и меток времени.
- Тайм-коды сверяются на сервере с сегментами Apify; выдуманные или повреждённые метки удаляются.
- YouTube-ссылка строится только из проверенного ID ролика и целого числа секунд.
- Без CAPTCHA учебный сервис не рассчитан на защиту от массового создания фальшивых аккаунтов.

## Проверка перед публикацией

```powershell
npm test
```

Затем нужно проверить регистрацию, начальный баланс 10/10, списание и возврат кредита, RU/EN/LV, ширину 390 px, клавиатурную навигацию, консоль браузера и публичную ссылку в режиме инкогнито. В репозитории и архиве не должно быть реальных ключей и файлов `.env*`.
